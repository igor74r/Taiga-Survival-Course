## Обязательные правила запуска игры

1. Единственная рабочая версия игры — файлы этого репозитория в ветке `main`.
2. Кнопка запуска в описании репозитория должна открывать именно работающую игру в браузере, а не страницу с исходным кодом.
3. Точка входа для запуска должна быть доступна из корня репозитория; при необходимости структура проекта и загрузка ресурсов должны быть адаптированы под такой запуск.
4. Перед сдачей проверить фактическое нажатие кнопки в браузере: должен появляться игровой интерфейс, а не текст HTML.
5. Запрещены Codespaces, сторонние хостинги, внешние площадки, CDN, прокси, удалённые среды и внешние сервисы запуска.
6. Не предлагать и не подключать альтернативные внешние способы публикации. Не менять это правило без прямого указания пользователя.

## Принцип организации

Материалы сериала и игровой проект хранятся отдельно. Игровая концепция самостоятельная: сериал служит отдельным исследовательским направлением, а не автоматически источником игрового канона.
