## Запуск игры прямо из репозитория

Игра запускается в браузере через **GitHub Codespaces** — среду разработки, которая открывает этот репозиторий и запускает локальный веб-сервер. Скачивать архив или переносить исходники на другой хостинг не требуется.

1. Откройте [репозиторий](https://github.com/igor74r/Taiga-Survival-Course).
2. Нажмите **Code → Codespaces → Create codespace on main**.
3. Дождитесь запуска среды. Настройка проекта автоматически запускает сервер на порту **8000**.
4. Откройте вкладку **Ports** в нижней панели Codespaces.
5. У порта **8000** нажмите **Open in Browser**.

Игра откроется в браузере из рабочей копии репозитория. Для повторного запуска используйте тот же Codespace и порт 8000.

Если сервер не запустился автоматически, откройте терминал Codespaces и выполните:

```bash
python3 -m http.server 8000 --directory GAME_TAIGA_IDLE
```

Затем откройте порт 8000 во вкладке **Ports**. Доступность Codespaces и его квоты зависят от аккаунта.

**Важно:** обычная страница просмотра файла `index.html` на GitHub не исполняет игру. Для браузерного запуска нужна среда Codespaces или локальный веб-сервер.

Сохранение хранится в localStorage браузера и привязано к адресу открытой среды. Не очищайте данные сайта, если хотите сохранить прогресс.

## Реализовано в прототипе
- мобильный адаптивный интерфейс;
- базовые параметры выживания: здоровье, сытость, жажда, бодрость, тепло и мораль;
- ресурсы и склад;
- лагерь, костёр, отдых, еда и укрепление навеса;
- назначаемые Idle-работы с очередью и автоматическим завершением;
- рецепты и расход ресурсов;
- карта ближайших точек интереса и исследование;
- локальное автосохранение;
- ограниченный офлайн-прогресс до 8 часов.

## Техническое состояние и ограничения

Это ранний браузерный PWA-прототип, а не готовая Android-сборка. Полноценная система экспедиций, сюжетные цепочки, болезни, сезоны, производственные станции и аудио ещё не реализованы. Баланс предварительный.

Сохранения проходят миграцию формата v1 → v2 через `src/services/save-service.js`. GitHub Actions проверяет основные файлы, JSON-манифест, синтаксис JavaScript и начальные regression/unit/runtime tests. Эти проверки не покрывают все игровые механики. Проверка на физическом Android-устройстве не проводилась.

## Правила дальнейшей разработки

Перед изменением кода сверяйтесь с [PROJECT_MAP.md](./PROJECT_MAP.md) и главным мастер-промтом. После изменения игровых систем обновляйте тесты и документацию, затем проверяйте GitHub Actions.
