# TAIGA — IDLE SURVIVAL

Первый игровой вертикальный срез проекта по [главному мастер-промту](./GAME_PROMPT_TAIGA_IDLE_SURVIVAL.md).

## Навигация по проекту

- [Карта файлов и архитектуры](./PROJECT_MAP.md) — где находятся игровые системы, тесты и служебные файлы.
- [Главный мастер-промт](./GAME_PROMPT_TAIGA_IDLE_SURVIVAL.md) — обязательные требования к игре.
- [Технический аудит от 2026-11-06](./AUDIT_2026-11-06.md) — известные проблемы и план исправлений.

## Запуск

Откройте `index.html` в современном браузере на телефоне или компьютере. Сборка и установка не требуются. Сохранение хранится локально в браузере (localStorage). При размещении по HTTPS прототип поддерживает установку как PWA и кеширование основных файлов для офлайн-запуска. Публичный запуск и установка пока не подтверждены.

## Реализовано в прототипе

- мобильный адаптивный интерфейс;
- базовые параметры выживания: здоровье, сытость, жажда, бодрость, тепло и мораль;
- ресурсы и склад;
- лагерь, костёр, отдых, еда и укрепление навеса;
- назначаемые Idle-работы с очередью и автоматическим завершением;
- рецепты и расход ресурсов;
- карта ближайших точек интереса и исследование;
- локальное автосохранение;
- ограниченный офлайн-прогресс до 8 часов.

## Техническое состояние и ограничения

Это ранний браузерный PWA-прототип, а не готовая Android-сборка. GitHub Pages не настроен. Полноценная система экспедиций, сюжетные цепочки, болезни, сезоны, производственные станции и аудио ещё не реализованы. Баланс предварительный.

Сохранения проходят миграцию формата v1 → v2 и базовую очистку типов/диапазонов через `src/services/save-service.js`. GitHub Actions проверяет наличие основных файлов, JSON-манифест, синтаксис JavaScript, статические contract checks и unit-тесты сервиса сохранений (`tests/save-service.test.cjs`). Дополнительно `tests/game-runtime.test.cjs` запускает игровой скрипт в тестовом окружении и проверяет крафт факела, успешное и неуспешное разведение костра. Это начальное покрытие, а не полный набор тестов всех игровых механик. Проверка на физическом Android-устройстве не проводилась.

## Правила дальнейшей разработки

Перед изменением кода сверяйтесь с [PROJECT_MAP.md](./PROJECT_MAP.md) и главным мастер-промтом. После изменения игровых систем обновляйте тесты и документацию, затем проверяйте GitHub Actions.
