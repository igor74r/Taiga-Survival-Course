# TAIGA — IDLE SURVIVAL

Первый игровой вертикальный срез проекта по [главному мастер-промту](./GAME_PROMPT_TAIGA_IDLE_SURVIVAL.md).

## Навигация по проекту
- [Карта файлов и архитектуры](./PROJECT_MAP.md) — структура игровых систем, тестов и служебных файлов.
- [Главный мастер-промт](./GAME_PROMPT_TAIGA_IDLE_SURVIVAL.md) — обязательные требования к игре.
- [Технический аудит](./AUDIT_2026-11-06.md) — известные проблемы и план исправлений.

## Запуск игры в браузере

Нажмите [▶ ЗАПУСТИТЬ ИГРУ](./index.html) — откроется файл игры `index.html` в текущей ветке репозитория.

- Работает в мобильном и настольном браузере.
- Не требует среды разработки, терминала, установки Python или ручного запуска сервера.
- Все исходники и игровые ресурсы должны находиться в `GAME_TAIGA_IDLE/` и храниться в ветке `main`.
- Прогресс сохраняется в `localStorage` браузера. При смене браузера или очистке данных сайта локальное сохранение не переносится.

## Запрет внешних сервисов

Для запуска и доставки игры запрещено использовать сторонние хостинги, CDN, прокси, внешние площадки, Codespaces и любые внешние среды. Не добавлять такие адреса в кнопки запуска, README, мастер-промт или конфигурацию игры. Единственный источник игровых файлов — этот репозиторий, ветка `main`.

Важно: GitHub показывает HTML-файл репозитория как исходный код и сам по себе не исполняет его как веб-игру.

## Реализовано в прототипе
- мобильный адаптивный интерфейс;
- базовые параметры выживания: здоровье, сытость, жажда, бодрость, тепло и мораль;
- ресурсы и склад;
- лагерь, костёр, отдых, еда и укрепление навеса;
- назначаемые Idle-работы с очередью и автоматическим завершением;
- рецепты и расход ресурсов;
- карта ближайших точек интереса и исследование;
- локальное автосохранение;
- ограниченный офлайн-прогресс до 8 часов.

## Техническое состояние и ограничения

Это ранний браузерный PWA-прототип, а не готовая Android-сборка. Полноценная система экспедиций, сюжетные цепочки, болезни, сезоны, производственные станции и аудио ещё не реализованы. Баланс предварительный.

Сохранения проходят миграцию формата v1 → v2 через `src/services/save-service.js`. GitHub Actions проверяет основные файлы, JSON-манифест, синтаксис JavaScript и начальные regression/unit/runtime tests. Эти проверки не покрывают все игровые механики. Проверка на физическом Android-устройстве не проводилась.

## Правила дальнейшей разработки

Перед изменением кода сверяйтесь с [PROJECT_MAP.md](./PROJECT_MAP.md) и главным мастер-промтом. После изменения игровых систем обновляйте тесты и документацию, затем проверяйте GitHub Actions.
